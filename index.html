Selected Projects

DataAgentDemo

DataPilot is a Streamlit and DuckDB demo for exploring six months of simulated e-commerce data. It turns plain-language questions into read-only SQL, visualizes changes in sales and conversion, and lets users test how restocking might affect sales.

ArbLensMonitor-Installer

ArbLens Monitor compares prices and funding rates for perpetual futures across crypto exchanges. It uses order-book depth to estimate entry spreads at a chosen trade size and provides historical charts and alerts for spread changes. This repository publishes the installer for Ubuntu 22.04 and 24.04.

MScProject

A collection of projects from my MSc in Data Science, covering AI and text analytics, large-scale data engineering, and software development for data analysis. It also includes Tableau coursework on exploring and communicating data visually.

RecommendationSys

A hands-on study of how recommender systems retrieve and rank items. The repository pairs notes on recommendation methods with an H&M product recommendation notebook that uses purchase history to generate candidate products.

Python_Data_Analysis

A collection of Jupyter notebooks and notes that follows the Python data analysis workflow, from cleaning data with NumPy and pandas to visualization, feature engineering, and time series analysis. It includes a Titanic analysis example and notes on SQL, Hadoop, and Spark.
